# Shell, loops, conditions and parsing

This project contains Bash scripting exercises focused on loops, conditions, and log parsing.

## Tasks
* **1-for_best_school**: Loops 10 times displaying "Best School" using `for`.
* **2-while_best_school**: Loops 10 times displaying "Best School" using `while`.
* **3-until_best_school**: Loops 10 times displaying "Best School" using `until`.
* **4-if_9_say_hi**: Loops 10 times displaying "Best School" and says "Hi" on the 9th iteration.
* **5-4_bad_luck_8_is_your_chance**: Loops 1 to 10 displaying "bad luck" for 4, "good luck" for 8, and "Best School" for others.
* **6-superstitious_numbers**: Loops 1 to 20 displaying numbers with superstitious messages using `case`.
* **7-clock**: Displays a 12 hour, 59 minute clock.
* **8-for_ls**: Lists directory contents showing name after the first dash.
* **9-to_file_or_not_to_file**: Information about file `school`.
* **10-fizzbuzz**: FizzBuzz from 1 to 100.
* **11-read_and_cut**: Displays username, UID, and home directory from `/etc/passwd`.
* **12-tell_the_story_of_passwd**: Tells the story of `/etc/passwd` using IFS.
* **13-lets_parse_apache_logs**: Parses visitor IP and HTTP code using `awk`.
* **14-dig_the-data**: Groups, counts and sorts visitor IPs and HTTP codes using `awk`.
